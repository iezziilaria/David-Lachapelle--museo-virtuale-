# LaChapelle Digital Museum

Interactive web project inspired by the artistic universe of David LaChapelle.

## Overview

This project is a multi-page digital museum experience developed using HTML and CSS.  
It explores visual storytelling, online exhibition design, and artistic presentation through a responsive web interface.

## Technologies

- HTML5
- CSS3

## Features

- Multi-page navigation
- Digital gallery sections
- Artistic visual layout
- Interactive museum-inspired structure
